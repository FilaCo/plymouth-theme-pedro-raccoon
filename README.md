# Pedro Raccoon Plymouth

A simple Plymouth theme featuring the Pedro Raccoon meme.

![Pedro raccoon meme](pedro-raccoon.gif)

## Installation

You can either clone the repository or download the ZIP.

### Option 1: Clone the repository (permissions preserved)

```bash
git clone https://github.com/FilaCo/plymouth-theme-pedro-raccoon.git
cd plymouth-theme-pedro-raccoon
```

Make the installer executable (usually not needed if cloned via Git):

```bash
chmod +x install
```

Run the installer:

```bash
sudo ./install
```

The <b>install</b> invokes <b>sudo</b> so you will be asked to add your password .

### Option 2: Download the ZIP (permissions not preserved)

1. Download the ZIP from GitHub
2. Extract it and enter the folder:

```bash
cd plymouth-theme-pedro-raccoon
```

3. Make the installer executable:

```bash
chmod +x install
```

4. Run the installer:

```bash
sudo ./install
```

# To Uninstall

1. Move to dir
```bash
cd plymouth-theme-pedro-raccoon
```

2. Run the uninstall command
```bash
./install uninstall
```

The <b>install</b> invokes <b>sudo</b> so you will be asked to add your password .

<b>Restart your machine and enjoy</b>
